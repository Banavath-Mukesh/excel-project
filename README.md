# 🍕 Pizza Sales Analysis Dashboard

**Author:** Banavath Mukesh

## Overview

This project features an interactive Excel dashboard for analyzing pizza sales data. It transforms raw transaction data into actionable insights for business strategy, inventory management, and customer engagement.

## Key Features

- **Comprehensive Dashboard:** Visualizes sales by hour, day, month, pizza size, and category.
- **KPI Tracking:** Monitors total sales ($817,860), average order value ($38), total pizzas sold (49,574), and orders (21,350).
- **Dynamic Filters:** Slicers for real-time analysis by pizza size and category.
- **Product Insights:** Identifies best- and worst-selling pizzas for menu optimization.

## Technologies

- **Microsoft Excel 365:** Advanced formulas, PivotTables, charts, and slicers.

## How to Use

1. Open the dataset in the `Dataset/` folder.
2. Explore the dashboard in the `Dashboard/` folder (`Pizza_Sales_Dashboard.xlsx`).
3. Use slicers and charts for interactive analysis.

## Project Structure

- `Dashboard/` – Excel dashboard
- `Dataset/` – Raw sales data
- `Images/` – Dashboard screenshots
- `README.md` – Project documentation
